# 我的算法学习笔记

本文件夹用于存放我的学习笔记，每学一个知识点新建一个 Markdown 文件。

## 文件命名建议

```
notes/
├── README.md          ← 这个文件
├── 01-基础数据结构.md
├── 02-排序算法.md
└── ...
```

## 日常流程

```bash
# 1. 写笔记（用 VS Code 打开 notes 文件夹编辑）
# 2. 提交
git add notes/
git commit -m "添加XX笔记"
# 3. 推送到 GitHub（第一次需要登录）
git push
```
